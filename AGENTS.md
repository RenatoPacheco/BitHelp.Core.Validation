# AGENTS.md

.NET validation library (NuGet package `BitHelp.Core.Validation`). Run all commands from the repo root.

## Layout

- `BitHelp.Core.Validation.sln` contains two projects:
  - `src/` is the library, targeting `netstandard2.0`.
  - `test/` is the xUnit project, targeting `net7.0`. It references `src/`.
- `test/Demo/` is sample code compiled into the test assembly. It has no tests.
- Validators come in pairs:
  - `src/Extends/*IsValidExt.cs` holds the fluent extension methods, for `ISelfValidation` and `ValidationNotification`.
  - `src/Notations/*IsValidAttribute.cs` holds the DataAnnotations attributes, based on `BaseIsValidAttribute`.
  - Each pair has tests in `test/ExtendsTest/` and, where applicable, `test/NotationsTest/`.
- Messages are localized through `src/Resources/Resource.resx` and `Resource.pt-BR.resx`.
  - `Resource.Designer.cs` is not regenerated by `dotnet build`. When you add a key, add it to both `.resx` files and hand-edit the designer file.
  - Keys `Bitmap1`, `Color1`, `Icon1`, `Name1` exist in the `.resx` files but not in the designer. This is expected.

## Commands

```
dotnet restore
dotnet build --no-restore
dotnet test --no-build --verbosity normal
```

- Run `build` before `test`. Tests use `--no-build`, so they run whatever binary is currently built.
- Single test (filter by name):
  `dotnet test --no-build --filter "FullyQualifiedName~RequiredIsValid"`
- Full coverage report: `./buildReport.sh`. It is a bash script and needs `reportgenerator` (`dotnet tool install --global dotnet-reportgenerator-globaltool --version 4.8.6`). Output goes to `coverage/report/`.
- Packaging: `dotnet pack src --configuration Release` writes `.nupkg` to `nuget/` at the repo root (gitignored).

## Constraints

- Library code (`src/`) must stay compatible with C# 7.3, the default for `netstandard2.0`. No target-typed `new()`. Tests use modern C#.
- CI (`.github/workflows/`) uses .NET SDK 7.0.x. The local machine has SDK 10, which also builds and tests this repo.
- The "Integration Tests" workflow only runs the unit tests. No external services are required. The suite runs in under a second.
- Line endings: working-tree files are CRLF (`.editorconfig` requires CRLF, UTF-8 with BOM). The index stores LF. Keep CRLF when editing files.
- Versioning is manual. Bump `<Version>` in `src/BitHelp.Core.Validation.csproj`, then add a section to `RELEASES.md` and update the "Latest releases" section in `README.md`.
- Publishing is manual. Run the "Build & Publish packages" workflow with `workflow_dispatch`. Pushing to `master` does not publish.
